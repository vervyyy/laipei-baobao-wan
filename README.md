# 来陪宝宝玩

一个纯本地跑的小工具：词穷不知道跟宝宝玩什么的时候，点开刷一刷，找点真实生活里能做的活动。不是打卡清单，没有进度、没有"还剩几个没做"。

目前内置的是 18-24 个月（1.5-2 岁）的内容，在 `content.json` 里可以直接改成适合你家宝宝的月龄段。

## 想要一份属于你家宝宝的定制版？

不用会写代码。下载这个仓库后，用 Trae / CodeBuddy 这类AI编程工具打开文件夹，跟它说一句"读一下《[定制成你家宝宝专属版.md](./定制成你家宝宝专属版.md)》，照着做"，AI会先问你几个关于宝宝的问题，然后帮你改成专属版本。

## 怎么跑起来

需要电脑上装了 Python 3（Mac 自带，不用额外安装）。

1. 下载/克隆这个文件夹
2. 打开终端，进到这个文件夹里
3. 运行：

```bash
python3 server.py
```

4. 看到提示后，电脑上打开 `http://localhost:8877`

## 手机上怎么用

手机连到**和电脑同一个 WiFi**，浏览器打开终端里提示的 `http://xxx.xxx.xxx.xxx:8877` 这个地址（电脑的局域网地址，每次启动会打印出来）。

可以在手机浏览器里把这个页面"添加到主屏幕"，就能像个 App 一样点开用。

注意：电脑需要开着、`server.py` 需要一直在跑，手机才能访问到。

## 数据存在哪

所有内容（日记、本周计划、玩具清单、屏幕时间）都存在这个文件夹下的 `data.json` 里，只在你自己电脑上，不会上传到任何地方。删掉这个文件就是清空重来。

## 想自己改内容

- `content.json`：五个模块（大运动/精细动作/语言启蒙/认知启蒙/社交情感）的活动库，每个模块是个数组，随便加减改
- `style.css` 里的 CSS 变量（顶部 `:root`）：改配色
- 换月龄段：把 `content.json` 里的活动换成对应月龄的内容，`ageLabel` 也改一下

Fork 了之后按自己家宝宝的情况改就行，这个项目不会持续维护更新。
